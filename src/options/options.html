Redirection de domaines

Remplace le domaine d'une URL par un autre en conservant le chemin, les paramètres et l'ancre.

Autorisations manquantes. Chrome exige un accès explicite aux domaines source et cible pour pouvoir rediriger.

Redirections

La première redirection dont le domaine source correspond est appliquée. Glissez l'ordre avec les flèches si plusieurs règles se recoupent.

    Aucune redirection pour l'instant. Exemple : alias.client.fr → client-prod-1234.odoo.com.

    Tester une URL

    Collez une URL reçue d'un utilisateur pour vérifier où elle sera redirigée.

    Sauvegarde

    Les redirections sont synchronisées avec votre compte Chrome. L'export permet de les partager avec un collègue.
