Redirection de domaines

Réécrit le domaine d'une URL en conservant chemin, paramètres et ancre, et ouvre une recherche depuis un raccourci clavier.

Autorisations manquantes. Chrome exige un accès explicite aux domaines source et cible pour pouvoir rediriger.

Redirections

La première redirection dont le domaine source correspond est appliquée. Réordonnez avec les flèches si plusieurs règles se recoupent.

    Aucune redirection pour l'instant. Exemple : odoo.client.fr → client-prod-1234.odoo.com.

    Tester une URL

    Collez une URL reçue d'un utilisateur pour vérifier où elle sera redirigée.

    Environnements

    L'URL de base sur laquelle la recherche est lancée : une instance Odoo, un environnement de test… Le lanceur permet de basculer de l'un à l'autre (Alt+1…9).

      Aucun environnement. Exemple : https://client-prod-1234.odoo.com.

      Recherches

      Le modèle d'URL contient {q}, remplacé par la valeur saisie dans le lanceur. Relatif à l'environnement (/odoo/helpdesk/{q}) ou absolu (https://support.example.com/t/{q}). Pour Odoo 16 et antérieur : /web#id={q}&model=helpdesk.ticket&view_type=form. Le mot-clé permet de choisir la recherche depuis le champ de saisie : t 1234.

        Aucune recherche configurée.

        Raccourcis clavier

        Le lanceur s'ouvre par défaut avec Alt+Maj+O. Chrome permet de choisir n'importe quelle combinaison, et d'attribuer une touche aux trois raccourcis rapides ci-dessous, qui ouvrent directement le lanceur sur une recherche et un environnement donnés.

          Sauvegarde

          Redirections, environnements et recherches sont synchronisés avec votre compte Chrome. L'export permet de les partager avec un collègue.
